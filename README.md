# Mobile-Sales-Dashboard-Power-BI
Interactive Power BI Dashboard for Mobile Sales Analysis using DAX, Power Query and Time Intelligence.

# 📊 Mobile Sales Dashboard | Power BI

An interactive **Power BI dashboard** developed to analyze mobile sales data. This project provides business insights through KPIs, interactive visualizations, DAX measures, and Time Intelligence functions.

---

# 📖 Project Overview

The objective of this project is to transform raw mobile sales data into meaningful business insights. The dashboard allows users to monitor sales performance, compare trends over time, analyze customer ratings, evaluate payment methods, and explore data using interactive filters.

# 🎯 Dashboard Capabilities

- Analyze sales performance by Brand, Mobile Model, City, and Time.
- Compare Month-To-Date (MTD) sales with the Same Period Last Year (SPLY).
- Monitor key business KPIs including Total Sales, Quantity, Transactions, and Average Price.
- Evaluate customer ratings and payment methods.
- Explore data dynamically using interactive slicers and cross-filtering.
